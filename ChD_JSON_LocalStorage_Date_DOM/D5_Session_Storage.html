What is Session Storage?

Session Storage is a browser storage system used to store temporary data.

The data remains stored until the browser tab is closed.

It stores data in key : value format.

Features

• Temporary storage
• Removed after tab closes
• Stores only strings
• Faster than cookies
• Data not shared between tabs

setItem()

Used to store data.

Syntax:

sessionStorage.setItem("key","value");

Example:

sessionStorage.setItem("username","Sam");

getItem()

Used to retrieve stored data.

Syntax:

sessionStorage.getItem("key");

removeItem()

Removes specific stored data.

Syntax:

sessionStorage.removeItem("key");

clear()

Removes all stored session data.

Syntax:

sessionStorage.clear();

JSON with Session Storage

Objects and arrays must be converted into strings.

Example:

let student = {
    name : "Sam"
};

sessionStorage.setItem(
    "student",
    JSON.stringify(student)
);
