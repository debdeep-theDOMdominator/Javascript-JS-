Ch D / Part II : "LOCAL STORAGE" in JS

What is Local Storage?

LocalStorage is used for persistent data storage in the browser. The data remains saved even after refreshing or closing the browser.


setItem()

Stores data as key-value pairs.
Example:
localStorage.setItem("name", "Rahul");
localStorage.setItem("age", "20");


Only Strings Allowed

LocalStorage can only store strings.
To store objects, convert them using JSON.
Example:
let user = { name: "Rahul", age: 20 };
localStorage.setItem("user", JSON.stringify(user));


getItem()

Retrieves data based on key.
Example:
let name = localStorage.getItem("name");
console.log(name);

let userData = JSON.parse(localStorage.getItem("user"));
console.log(userData.name);


Other Methods

removeItem() → Removes a specific key.
clear() → Clears all data.

Examples:
localStorage.removeItem("name");
localStorage.clear();


Important Note

Do NOT store sensitive information (like passwords).
Data is visible in the browser’s Storage Console (DevTools).
