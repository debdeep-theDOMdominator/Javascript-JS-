DOM & Element Properties

1. location
Definition: Gives information about current URL.
Syntax: window.location
Example: console.log(window.location.href);


2. title
Definition: Gets or sets the page title.
Syntax: document.title
Example: document.title = "New Title";


3. href
Definition: Gets or sets the full URL of a link.
Syntax: element.href
Example: document.querySelector("a").href;


4. domain
Definition: Returns the domain name of the page.
Syntax: document.domain
Example: console.log(document.domain);


5. innerHTML
Definition: Gets or sets HTML content inside an element.
Syntax: element.innerHTML
Example: document.getElementById("demo").innerHTML = "Hello";


6. innerText
Definition: Gets or sets only text content (no HTML).
Syntax: element.innerText
Example: document.getElementById("demo").innerText = "Hello";


7. classList
Definition: Used to add/remove CSS classes.
Syntax: element.classList
Example: element.classList.add("active");


DOM & Element Methods

1. getElementById()
Definition: Selects element by ID.
Syntax: document.getElementById("id")
Example: let el = document.getElementById("demo");


2. querySelector()
Definition: Selects first matching element (CSS selector).
Syntax: document.querySelector("selector")
Example: document.querySelector(".box");


3. classList.add() / remove()
Definition: Adds or removes class.
Syntax: element.classList.add("class")
Example: el.classList.remove("active");


4. createElement()
Definition: Creates a new HTML element.
Syntax: document.createElement("tag")
Example: let div = document.createElement("div");


5. appendChild()
Definition: Adds element inside parent.
Syntax: parent.appendChild(child)
Example: document.body.appendChild(div);


6. removeChild()
Definition: Removes child element.
Syntax: parent.removeChild(child)
Example: parent.removeChild(div);


7. replaceChild()
Definition: Replaces one child with another.
Syntax: parent.replaceChild(newChild, oldChild)
Example: parent.replaceChild(newDiv, oldDiv);
