Ch D / Part I : "JSON" in JS

What is JSON ?

JSON (JavaScript Object Notation) is a data format. It looks similar to JavaScript objects but is not the same.


Key Difference :

JSON is a data format, whereas a JavaScript object is a data structure used in code.


Where is JSON used ?

JSON is commonly used in network calls (APIs) and data storage because it is easy to send and receive.


Why JSON ?

Strings are easy to transport over networks, so JSON converts data into string format.


JSON Rules :

JSON requires double quotes for keys and values.
Example: { "name": "Rahul" }
Double quotes inside JSON are escaped using \".


JSON Methods :

JSON.stringify() → Converts JavaScript object into JSON string.
JSON.parse() → Converts JSON string back into JavaScript object.


Example :

let obj = { name: "Rahul", age: 20 };

let jsonData = JSON.stringify(obj);
console.log(jsonData);

let backToObj = JSON.parse(jsonData);
console.log(backToObj.name);


Important Note :

JSON is only for data exchange, while JavaScript objects can also contain functions and logic.
