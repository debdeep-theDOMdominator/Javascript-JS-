Ch D / Part V : "COOKIES" in JS

What are Cookies?

Cookies are small pieces of data stored in the browser.

Mainly used for:

• Authentication
• Login sessions
• User tracking
• Saving preferences

Features of Cookies

• Stored in browser
• Sent with every HTTP request
• Can expire after specific time
• Stores only strings

Basic Syntax

Syntax:

document.cookie = "key=value";

Example:

document.cookie = "username=Sam";

Expiry Date

Cookies can expire after some time.

Example:

document.cookie =
"username=Sam; expires=Fri, 31 Dec 2027 12:00:00 UTC";

Cookie Path

Path decides where cookie can be accessed.

Example:

document.cookie = "theme=dark; path=/";

Reading Cookies

Syntax:

document.cookie;

Returns all cookies as a string.

Deleting Cookies

Cookies are deleted using old expiry date.

Example:

document.cookie =
"username=Sam; expires=Thu, 01 Jan 1970 00:00:00 UTC";

Cookie Problems

• Stores only strings
• Expiry handled manually
• Sent with requests
• Excessive cookies reduce performance
