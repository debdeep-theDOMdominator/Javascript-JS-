Ch K / Part I : " OOPS " in JS

What is OOP in JavaScript?

OOP stands for Object-Oriented Programming.

It is a programming style where code is organized using objects and classes.

OOP helps in:
• Better structure
• Reusability
• Modularity
• Encapsulation
• Easier maintenance


What are Objects?

Objects are collections of properties and methods.

Properties → Variables inside objects.
Methods → Functions inside objects.

Example:
let student = {
    name : "Sam",
    age : 21,

    show : function(){
        console.log(this.name);
    }
};


Constructor Functions

Before ES6 classes,
JavaScript used Constructor Functions to create objects.

Constructor functions act like blueprints for creating multiple objects.

Syntax:
function User(name,age){
    this.name = name;
    this.age = age;
}

let u1 = new User("Alex",22);


The new Keyword

The new keyword is used to create objects from constructor functions or classes.

When new is used:
• A new empty object is created
• this points to that object
• Properties are attached
• Object gets returned automatically


Example of Constructor Function

function Car(brand,model){
    this.brand = brand;
    this.model = model;
}

let c1 = new Car("BMW","X5");
let c2 = new Car("Audi","A6");

console.log(c1);
console.log(c2);


What are Prototypes?

Every JavaScript object has a hidden property called prototype.

Prototypes allow objects to share methods and properties.

Instead of creating duplicate methods for every object,
methods are stored once inside prototype.


Prototype Example

function Student(name){
    this.name = name;
}

Student.prototype.sayHello = function(){
    console.log("Hello " + this.name);
};

let s1 = new Student("Sam");

s1.sayHello();


Prototype Chain

JavaScript searches properties in a chain called the Prototype Chain.

First:
Object itself

Then:
Its prototype

Then:
Parent prototype

Until:
null


ES6 Classes

ES6 introduced the class syntax.

Classes are cleaner and easier ways to create objects.

Internally,
JavaScript still uses prototypes.


Class Syntax

Syntax:

class User{

    constructor(name,age){
        this.name = name;
        this.age = age;
    }

    show(){
        console.log(this.name);
    }
}

let u1 = new User("Alex",25);


Constructor Method

The constructor() method runs automatically when object is created.

It is mainly used for initialization.

Example:
class Test{
    constructor(){
        console.log("Object Created");
    }
}

let t1 = new Test();


Methods in Classes

Functions inside classes are called methods.

Example:
class Animal{

    sound(){
        console.log("Animal Sound");
    }
}


Inheritance in JavaScript

Inheritance allows one class to access properties and methods of another class.

This improves reusability.


extends Keyword

The extends keyword is used for inheritance.

Example:
class User{
    login(){
        console.log("User Logged In");
    }
}

class Admin extends User{
    deleteUser(){
        console.log("User Deleted");
    }
}


super Keyword

The super keyword is used to call parent class constructor or methods.

Example:
class User{
    constructor(name){
        this.name = name;
    }
}

class Admin extends User{
    constructor(name){
        super(name);
    }
}


Encapsulation

Encapsulation means hiding internal data and controlling access.

JavaScript provides private fields using #.

Example:
class Bank{
    #balance = 5000;

    showBalance(){
        console.log(this.#balance);
    }
}


Private Fields

Variables starting with # are private.

They cannot be accessed outside the class.

Example:
class Test{
    #x = 10;
}

let t1 = new Test();

// console.log(t1.#x); ❌ Error


Class Syntax vs Prototype Chain

ES6 classes are mainly cleaner syntax.

Internally,
JavaScript still uses prototype-based inheritance.

So:
Classes = Syntax Sugar over Prototypes


Shared vs Own Properties

Own Properties:
Stored directly inside object.

Shared Properties:
Stored in prototype and shared among all objects.


Bank Account Class Example

class BankAccount{

    constructor(owner,balance){
        this.owner = owner;
        this.balance = balance;
    }

    deposit(amount){
        this.balance += amount;
    }

    withdraw(amount){
        this.balance -= amount;
    }
}


User → Admin Inheritance Example

class User{
    login(){
        console.log("Login Success");
    }
}

class Admin extends User{
    removeUser(){
        console.log("User Removed");
    }
}

let a1 = new Admin();

a1.login();
a1.removeUser();
