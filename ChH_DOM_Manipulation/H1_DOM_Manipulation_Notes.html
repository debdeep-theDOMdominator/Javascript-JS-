What is DOM?

DOM stands for Document Object Model.

It is the structure of a webpage created by the browser.
JavaScript uses the DOM to access and manipulate HTML elements.

DOM works like a tree structure:
• Document
• HTML
• Head / Body
• Elements
• Text Nodes

DOM is the brain of the webpage.


DOM Tree Structure

Every HTML tag becomes a node in the DOM tree.

Types of Nodes:
• Element Node → HTML tags
• Text Node → Text inside elements
• Comment Node → HTML comments

Example:
<body>
    <h1>Hello</h1>
</body>


Selecting Elements

JavaScript can select HTML elements from the webpage.

1. getElementById()
Selects element using ID.

Syntax:
document.getElementById("idName");

Example:
let box = document.getElementById("demo");

2. getElementsByClassName()
Selects elements using class name.

Syntax:
document.getElementsByClassName("className");

3. querySelector()
Selects first matching element.

Syntax:
document.querySelector("selector");

Example:
let btn = document.querySelector(".btn");

4. querySelectorAll()
Selects all matching elements.

Syntax:
document.querySelectorAll("selector");


Text & Content Access

DOM allows changing text and HTML content.

1. innerText
Gets only visible text.

Example:
element.innerText = "Hello";

2. textContent
Gets all text including hidden text.

Example:
element.textContent = "New Text";

3. innerHTML
Gets or sets HTML content.

Example:
element.innerHTML = "<b>Bold</b>";


Difference : innerText vs textContent vs innerHTML

innerText
• Only visible text
• Ignores hidden text

textContent
• Returns all text
• Faster than innerText

innerHTML
• Reads/writes HTML tags also
• Can insert HTML elements


Attribute Manipulation

Attributes of elements can be changed using JavaScript.

1. getAttribute()
Gets attribute value.

Example:
element.getAttribute("href");

2. setAttribute()
Sets new attribute value.

Example:
element.setAttribute("href","https://google.com");

3. removeAttribute()
Removes attribute.

Example:
element.removeAttribute("disabled");


Dynamic DOM Manipulation

JavaScript can create and remove elements dynamically.

1. createElement()
Creates new HTML element.

Example:
let p = document.createElement("p");

2. appendChild()
Adds child inside parent.

Example:
document.body.appendChild(p);

3. prepend()
Adds element at beginning.

Example:
document.body.prepend(p);

4. removeChild()
Removes child element.

Example:
parent.removeChild(child);


Style Manipulation

CSS styles can be changed using JavaScript.

1. style
Directly changes CSS.

Example:
element.style.color = "red";
element.style.backgroundColor = "black";

2. classList
Used to manage CSS classes.

Methods:
• add()
• remove()
• toggle()

Example:
element.classList.add("active");


HTMLCollection vs NodeList

HTMLCollection
• Live Collection
• Updates automatically
• Returned by getElementsByClassName()

NodeList
• Static Collection
• Does not auto-update
• Returned by querySelectorAll()
