Ch i / Part I : "Forms & Form Validation" using JS

What are Forms?

Forms are used to collect user data from webpages.

Examples:
• Login Form
• Signup Form
• Feedback Form
• Contact Form


Reading Values from Forms

JavaScript can read values entered by users inside:

• input
• textarea
• select

Example:
let userName = document.querySelector("#username");

console.log(userName.value);


input, textarea & select

1. input
Used for single-line data.

Examples:
• Name
• Email
• Password

2. textarea
Used for multi-line text.

Example:
Feedback Message

3. select
Used to create dropdown menus.


What is Form Validation?

Validation means checking whether user input is correct or not.

Examples:
• Email format check
• Password length check
• Empty input check
• Phone number check


Prevent Default Form Submission

By default, forms refresh the page after submission.

To stop this behavior, use:

event.preventDefault()

Example:
form.addEventListener("submit", function(event){
    event.preventDefault();
    console.log("Form Submitted");
});


Inline Validation

Inline validation uses HTML attributes for validation.

Examples:
• required
• minlength
• maxlength
• pattern

Example:
<input type="email" required>


JavaScript-Based Validation

JavaScript validation checks values using conditions.

Example:
if(password.value.length < 8){
    console.log("Weak Password");
}


Showing Error Messages

Error messages can be shown conditionally.

Example:
if(email.value === ""){
    error.innerText = "Email Required";
}


Pattern Attribute vs Regex

Pattern Attribute
Validation directly inside HTML.

Example:
<input pattern="[0-9]{10}">

Regex (Regular Expression)
Validation using JavaScript.

Example:
let regex = /^[0-9]{10}$/;


Important Confusions

1. value vs textContent

• value → Gets input value
• textContent → Gets normal text inside element

Example:
input.value
div.textContent

2. Form Submission vs Button Click

• submit event → Form submitted
• click event → Button clicked


Mindset

Always:
• Sanitize inputs

• Prevent invalid data
