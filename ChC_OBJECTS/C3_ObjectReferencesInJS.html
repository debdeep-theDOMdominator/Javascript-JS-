Ch C / Part III : "OBJECT REFERENCING" in JS

What is Object Referencing ?

In JavaScript, objects work based on references, not actual stored values.


Key Concept :

When you assign an object to another variable, it copies the reference (memory address), not the actual object.


Example 1 :

let obj1 = { name: "Rahul" };
let obj2 = obj1;

obj2.name = "Amit";

console.log(obj1.name); // Amit

Changing obj2 also changes obj1 because both point to the same reference.


Comparing Objects :

When using == or ===, JavaScript compares references, not content.


Example 2 :

let a = { value: 10 };
let b = { value: 10 };

console.log(a == b); // false

Even though values are same, references are different.


Example 3 (Same Reference) :

let x = { num: 5 };
let y = x;

console.log(x == y); // true

Both variables point to the same object.


Important Note :

Changes made using one reference will affect all variables pointing to that object.
