Ch C / Part IV : "DESTRUCTURING & SHORTHAND" in JS

What is Destructuring ?

Destructuring means extracting properties from objects easily into variables.


Example :

let person = { name: "Rahul", age: 20 };

let { name, age } = person;

console.log(name); // Rahul
console.log(age); // 20


Multiple Extraction :

We can extract more than one property at once using destructuring.


"PROPERTY" Shorthand :

Instead of writing:
let message = "Hello";
let obj = { message: message };

We can write:
let obj = { message };


"METHOD" Shorthand :

We can define methods inside objects without using the function keyword.


Example :

let user = {
    name: "Rahul",
    greet() {
        console.log("Hello");
    }
};


Key Benefit :

Makes code shorter, cleaner, and easier to read.
