Ch C / Part I : OBJECTS in JS

What is an "OBJECT" ?

In JavaScript, an object is a data structure used to store multiple values in one variable, using 'key–value' pairs.


How "OBJECT" looks like ?

let Person = {
    name: "Rahul",
    age: 20,
    'is-Student': true
};


Dot Notation :

Use . operator to access values : Person.age


Bracket Notation :

Another way to access values is : Person['is-Student']


Key Benefit :

Organizes related data under a single name.


How to delete key-val pair in Objects ?

Using `delete` keyword : delete Person.age


How to delete Entire Object ?

JavaScript doesn’t have a direct “destroy object” command.
Instead, you remove its reference .
let person = { name: "Rahul" };
Do this : person = null;
