Ch C / Part II : AUTOBOXING in JS

What is "AUTOBOXING" ?

Autoboxing in JavaScript means automatic conversion of primitives into objects when needed.


Important Note :

The object created during autoboxing is temporary and gets destroyed immediately after use.


Why Autoboxing ?

It allows properties and methods to be used on primitive values like string, number, and boolean.


Key Point :

JavaScript temporarily wraps primitives into their object equivalents.


Example with String :

let name = "rahul";
console.log(name.length);
console.log(name.toUpperCase());

Here, "rahul" is a primitive string, but JavaScript converts it into a String object to use methods.


Example with Number :

let num = 12.345;
console.log(num.toFixed(2));

JavaScript converts the number into a Number object to apply the method.


Example with Boolean :

let isTrue = true;
console.log(isTrue.toString());

Boolean primitive is temporarily converted into a Boolean object.
