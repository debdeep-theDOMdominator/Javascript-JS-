Ch 01 / Part II : Output Methods or Debugging Methods in JS

Window Method : `alert` is a method of the global window object. It creates a modal popup box that interrupts the user and must be dismissed to continue. While they serve different functional purposes (console vs. UI popup), they are categorized together as JavaScript debugging tricks or logging levels when used to track code execution.

Console Methods : console.log, console.warn, and console.error are static methods of the global console object. They are used to print messages to the browser's developer console.

  • console.log: Outputs general information or variable values.
  • console.warn: Outputs a yellow-colored warning message, often with a warning icon.
  • console.error: Outputs a red-colored error message, typically used for critical failures.
