Ch L / Part I : " Callback , Promises & Async " in JS

Introduction to Asynchronous JavaScript

JavaScript can execute code in two ways:

1. Synchronous
Code runs line-by-line.
One task must finish before the next starts.

2. Asynchronous
Some tasks run later without blocking other code.

Example:
setTimeout(function(){
    console.log("Executed Later");
},2000);

Here, JavaScript continues running other code while waiting 2 seconds.


Synchronous vs Asynchronous JS

Synchronous JavaScript
• Executes one line at a time
• Blocking behavior
• Simple but can freeze execution

Example:
console.log("A");
console.log("B");
console.log("C");

Output:
A → B → C

Asynchronous JavaScript
• Non-blocking behavior
• Delayed tasks run later
• Improves performance

Example:
console.log("Start");

setTimeout(function(){
    console.log("Inside Timeout");
},2000);

console.log("End");

Output:
Start
End
Inside Timeout


What are Callbacks?

A Callback is a function passed into another function as an argument.

The callback runs later when needed.

Syntax:
function mainFunction(callback){
    callback();
}

Example:
function greet(name,callback){
    console.log("Hello " + name);
    callback();
}

function bye(){
    console.log("Bye");
}

greet("Sam",bye);


Callback Hell

Callback Hell happens when many nested callbacks make code difficult to read and manage.

This creates deeply nested code structures.

Example:
setTimeout(function(){
    console.log("Step 1");

    setTimeout(function(){
        console.log("Step 2");

        setTimeout(function(){
            console.log("Step 3");
        },1000);

    },1000);

},1000);

This is hard to maintain and debug.


What are Promises?

Promises are objects used to handle asynchronous operations more cleanly.

A Promise represents a future result.

Promise has 3 states:
• Pending
• Resolved (Fulfilled)
• Rejected

Syntax:
let promise = new Promise(function(resolve,reject){
});

Example:
let myPromise = new Promise(function(resolve,reject){
    let success = true;

    if(success){
        resolve("Task Completed");
    }
    else{
        reject("Task Failed");
    }
});


Using then() and catch()

then()
Executes when promise resolves.

catch()
Executes when promise rejects.

Example:
myPromise.then(function(result){
    console.log(result);
})
.catch(function(error){
    console.log(error);
});


Promise Chaining

Multiple asynchronous operations can be chained together.

Example:
fetchData()
.then(function(result){
    return processData(result);
})
.then(function(finalResult){
    console.log(finalResult);
})
.catch(function(error){
    console.log(error);
});


What is async?

The async keyword makes a function asynchronous.

Async functions always return a Promise.

Syntax:
async function functionName(){
}

Example:
async function hello(){
    return "Hello";
}

hello().then(function(result){
    console.log(result);
});


What is await?

The await keyword pauses execution until a Promise completes.

await can only be used inside async functions.

Example:
async function getData(){

    let result = await fetchData();

    console.log(result);
}


Async/Await with try...catch

Errors in async functions are handled using try...catch.

Example:
async function loadData(){

    try{
        let result = await fetchData();
        console.log(result);
    }

    catch(error){
        console.log(error);
    }

}


Important Confusions

1. Async functions always return Promises

Even if you return a normal value, JavaScript wraps it inside a Promise.

2. Mixing async/await with then()

Avoid mixing both styles unnecessarily.

Choose one style for cleaner code.


Mindset for Async JavaScript

Async is not magic.

It simply allows JavaScript to wait for long operations without freezing the entire program.

JavaScript continues running other tasks while waiting.


Real World Use Cases

Async JavaScript is heavily used for:

• File Uploads
• Timers
• Chat Applications

• Fetching User Data
