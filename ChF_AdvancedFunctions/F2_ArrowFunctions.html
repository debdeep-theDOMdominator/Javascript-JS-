What are Arrow Functions?

Definition: Arrow Functions are a short and concise way to write anonymous functions in JavaScript.

Syntax:
let functionName = () => { };

Example:
let greet = () => {
    console.log("Hello");
};


Single Argument Rule

If an arrow function has only one argument, round brackets () are optional.

Normal Syntax:
let square = (n) => {
    return n*n;
};

Short Syntax:
let square = n => {
    return n*n;
};


Single Line Rule

If the function contains only one line, curly brackets {} and return keyword are optional.

Normal Syntax:
let add = (a,b) => {
    return a+b;
};

Short Syntax:
let add = (a,b) => a+b;


Arrow Functions as Arguments

Arrow functions are commonly used while passing functions as arguments.

Example:
setTimeout(() => {
    console.log("Executed after 2 seconds");
},2000);


Important Notes

• Arrow functions are shorter and cleaner.
• Mostly used in callbacks and modern JavaScript.
• Useful with array methods like map(), filter(), forEach().

Example:
let nums = [1,2,3];
nums.forEach(num => console.log(num));
