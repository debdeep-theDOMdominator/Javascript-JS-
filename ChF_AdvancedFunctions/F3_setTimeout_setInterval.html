What are setTimeout() & setInterval()?

Definition: These functions are used to execute code asynchronously after a delay.

• setTimeout() runs code only once after a given time.
• setInterval() runs code repeatedly after fixed intervals.


setTimeout()

Definition: Executes a function once after a delay.

Syntax:
setTimeout(function, time);

Example:
setTimeout(function(){
    console.log("Executed after 2 seconds");
},2000);


clearTimeout()

Definition: Stops a timeout before it executes.

Syntax:
clearTimeout(timerID);

Example:
let timer = setTimeout(function(){
    console.log("Hello");
},3000);

clearTimeout(timer);


setInterval()

Definition: Repeats execution continuously after a fixed interval.

Syntax:
setInterval(function, time);

Example:
setInterval(function(){
    console.log("Running every 1 second");
},1000);


clearInterval()

Definition: Stops a running interval.

Syntax:
clearInterval(intervalID);

Example:
let interval = setInterval(function(){
    console.log("Repeated");
},1000);

clearInterval(interval);


Important Notes

• Time is measured in milliseconds.
• 1000 milliseconds = 1 second.
• Used for delays, animations, timers, games, notifications, etc.

Example:
setTimeout(() => console.log("Done"), 1000);
