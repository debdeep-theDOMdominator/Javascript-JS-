Ch F / Part I : "Anonymous Functions As Values" in JS

What are Anonymous Functions?

Definition: Anonymous Functions are functions without a name.
They are often assigned to variables or used directly where needed.

Functions in JavaScript are first-class citizens, which means they can be:
• Stored in variables
• Passed as arguments
• Returned from functions
• Stored inside objects

Example:
let greet = function(){
    console.log("Hello");
};


Functions as Values

Functions can be assigned to variables like any other value.

Syntax:
let variableName = function(){ };

Example:
let add = function(a,b){
    return a+b;
};

console.log(add(2,3));


Anonymous Functions inside Objects

Anonymous functions can also be stored as object properties.

Example:
let obj = {
    message : function(){
        console.log("Inside Object");
    }
};

obj.message();


Functions as Arguments

Anonymous functions can be passed as arguments to other functions.

Example:
setTimeout(function(){
    console.log("Executed Later");
},2000);


Invoking Anonymous Functions

Functions are invoked using () after the function name or variable.

Example:
let sayHi = function(){
    console.log("Hi");
};

sayHi();


Function Type Checking

console.log(myFunction) will show that it stores a function.
typeof also returns "function".

Example:
let test = function(){
    console.log("Testing");
};

console.log(test);
console.log(typeof test);
