Variable Declaration in JavaScript

JavaScript provides 3 keywords to declare variables:

  1. "var" : Old way, function-scoped, can be redeclared and updated.
  2. "let" : Block-scoped, can be updated but not redeclared in the same scope.
  3. "const" : Block-scoped, cannot be updated or redeclared (must be initialized at declaration).
var x = 10;
let y = 20;
const z = 30;

Variable Types in JavaScript

JavaScript is dynamically typed, meaning you don’t need to specify the type explicitly.

  1. Primitive Types
    • Number : Integers or decimals
      • let a = 42;
    • String : Text
      • let name = "John";
    • Boolean : true or false
      • let isActive = true;
    • Undefined : Declared but not assigned
      • let b;
    • Null : Intentional empty value
      • let c = null;
    • BigInt : Large integers
      • let big = 12345678901234567890n;
    • Symbol : Unique identifiers
      • let sym = Symbol("id");

  2. Non-Primitive (Reference) Types
    • Object : Collection of key-value pairs
      • let person = { name: "John", age: 25 };
    • Array : Ordered list
      • let arr = [1, 2, 3];
    • Function : Reusable block of code
      • function greet() { console.log("Hello"); }
