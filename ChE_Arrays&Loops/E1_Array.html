Ch E / Part I : "ARRAYS" in JS

What is an Array?

Definition: An Array is a list of values stored in a single variable.
Index: Starts from 0.
Use: Store multiple values together.

Example:
let arr = [10, 20, 30];
console.log(arr[0]); // 10


Array Syntax & Values

Definition: Arrays are created using [] and store values separated by commas.

Syntax:
let arr = [value1, value2, value3];

Rules:
• Use [] brackets
• Values separated by commas
• Can span multiple lines
• Can store any data type (even arrays)
• typeof array returns "object"

Example:
let data = [10, "Hello", true, [1,2]];
console.log(typeof data); // object


Array Properties

1. Array.isArray()
Definition: Checks if a variable is an array.
Syntax: Array.isArray(variable)
Example: Array.isArray([1,2,3]);

2. length
Definition: Returns number of elements.
Syntax: array.length
Example: let arr = [1,2,3]; console.log(arr.length);


Array Methods

1. push()
Definition: Adds element at end.
Example: arr.push(4);

2. pop()
Definition: Removes last element.
Example: arr.pop();

3. shift()
Definition: Removes first element.
Example: arr.shift();

4. unshift()
Definition: Adds element at beginning.
Example: arr.unshift(0);

5. splice()
Definition: Add/remove elements.
Syntax: arr.splice(index, count, newValue)
Example: arr.splice(1,1,"New");

6. toString()
Definition: Converts array to string.
Example: arr.toString();

7. sort()
Definition: Sorts array.
Example: arr.sort();

Rule :
sort() alone → strings
sort((a,b)=>a-b) → numbers ascending
sort((a,b)=>b-a) → numbers
8. valueOf()
Definition: Returns array itself.
Example: arr.valueOf();


Important Concepts

• Arrays use reference like objects.
• Destructuring works with arrays.

Example:
let arr = [10, 20];
let [a, b] = arr;
console.log(a, b);
