What is an Event?

Definition: Events are occurrences/actions that happen in a webpage.

Examples:
• Mouse Click
• Mouse Movement
• Keyboard Input
• Form Submission
• Scrolling

Real Life Example:
Birthday → Event
Function Call → Response


What are Event Listeners?

Event Listeners are used to detect and respond to user actions on a webpage.

They wait for an event to happen, then execute some code.


Using querySelector()

querySelector() is commonly used to select elements and attach event listeners.

Example:
let btn = document.querySelector("button");


Basic Syntax

Syntax:
element.addEventListener("event", function);

OR

element.addEventListener("event", () => { });

Example:
btn.addEventListener("click", function(){
    console.log("Button Clicked");
});


Most Important Events

1. click
Runs when user clicks.

btn.addEventListener("click", function(){
    alert("Clicked");
});

2. dblclick
Runs on double click.

btn.addEventListener("dblclick", function(){
    console.log("Double Clicked");
});

3. mouseover
Runs when mouse enters element.

box.addEventListener("mouseover", function(){
    console.log("Mouse Entered");
});

4. mouseout
Runs when mouse leaves element.

box.addEventListener("mouseout", function(){
    console.log("Mouse Left");
});


Mouse Events

mousedown
Runs when mouse button pressed.

mouseup
Runs when mouse button released.

mousemove
Runs continuously while moving mouse.

document.addEventListener("mousemove", function(){
    console.log("Moving");
});


Keyboard Events

keydown
Runs when key pressed.

document.addEventListener("keydown", function(event){
    console.log(event.key);
});

keyup
Runs when key released.


Input & Form Events

input
Runs while typing.

input.addEventListener("input", function(){
    console.log(input.value);
});

change
Runs when value changes.

focus
Runs when input selected.

blur
Runs when input loses focus.

submit
Runs when form submitted.


Window Events

load
Runs when page fully loads.

window.addEventListener("load", function(){
    console.log("Page Loaded");
});

resize
Runs when browser resized.

scroll
Runs during page scrolling.


Clipboard Events

copy
Runs when content copied.

cut
Runs when content cut.

paste
Runs when content pasted.


Multiple Event Listeners

Multiple event listeners can be added to the same element.

Example:
btn.addEventListener("click", function(){
    console.log("First Function");
});

btn.addEventListener("click", function(){
    console.log("Second Function");
});


Removing Event Listeners

removeEventListener() removes an attached event listener.

Syntax:
element.removeEventListener("event", functionVariable);

Example:
function hello(){
    console.log("Hello");
}

btn.addEventListener("click", hello);
btn.removeEventListener("click", hello);


The Event Object

JavaScript automatically provides event information using the event object.

Important Properties:
• event.target → Clicked element
• event.key → Pressed key
• event.type → Event name

Example:
document.addEventListener("keydown", function(event){
    console.log(event.key);
});


Arrow Function Style

Modern JavaScript commonly uses arrow functions with event listeners.

Example:
btn.addEventListener("click", () => {
    console.log("Clicked");
});
