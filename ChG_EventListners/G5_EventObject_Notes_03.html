Ch G / Part V : "Event Object Notes 03" in JS

What is the Event Object?

Definition: The event object is an object automatically created by JavaScript whenever an event happens.

It stores all information related to the event.

Examples:
• Which element was clicked
• Which key was pressed
• What type of event occurred
• Mouse position

Syntax:
element.addEventListener("event", function(event){
    // use event object
});


Accessing the Event Object

JavaScript automatically passes the event object into the callback function.

Example:
button.addEventListener("click", function(event){
    console.log(event);
});


event.target

Definition:
event.target returns the exact element on which the event happened.

It is very useful when working with multiple elements.

Syntax:
event.target

Example:
document.addEventListener("click", function(event){
    console.log(event.target);
});

If a button is clicked, event.target will return that button element.


event.type

Definition:
event.type returns the type/name of the event.

Examples:
• click
• mouseover
• keydown
• submit

Syntax:
event.type

Example:
button.addEventListener("click", function(event){
    console.log(event.type);
});

Output:
click


event.preventDefault()

Definition:
preventDefault() stops the browser's default action.

Common Uses:
• Stop form submission
• Stop page refresh
• Stop link navigation

Syntax:
event.preventDefault();

Example:
form.addEventListener("submit", function(event){
    event.preventDefault();
    console.log("Form Submission Stopped");
});


Why preventDefault() is Important?

Normally:
• Forms refresh the page after submit
• Links open another page

preventDefault() allows JavaScript to control what happens instead.


Example with Form

HTML:
<form>
    <input type="text">
    <button>Submit</button>
</form>

JavaScript:
let form = document.querySelector("form");

form.addEventListener("submit", function(event){
    event.preventDefault();
    console.log("Submitted Successfully");
});


Using Multiple Event Properties Together

Example:
button.addEventListener("click", function(event){
    console.log(event.target);
    console.log(event.type);
});


Real Life Analogy

Imagine a school bell ringing:

• Event → Bell Rang
• event.type → "bell"
• event.target → Which bell rang
• preventDefault() → Stop automatic school closing


Easy Memory Trick

event.target → "Who caused the event?"

event.type → "What event happened?"

preventDefault() → "Stop normal browser behavior"
