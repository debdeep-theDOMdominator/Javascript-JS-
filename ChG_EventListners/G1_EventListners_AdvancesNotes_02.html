What are Events?

Definition: Events are actions or occurrences that happen in the browser.

Examples:
• Clicking buttons
• Typing on keyboard
• Moving mouse
• Submitting forms
• Scrolling page

JavaScript can detect these events and respond to them.


What is Event Handling?

Event Handling means detecting an event and executing some code in response.

Flow:
User Action → Event Happens → Listener Detects → Function Runs


Event Listener

Event Listeners wait for events to happen and then run functions.

Syntax:
element.addEventListener("event", function(){ });

Example:
btn.addEventListener("click", function(){
    console.log("Clicked");
});


Event Binding

Attaching an event listener to an element is called Event Binding.

Example:
button.addEventListener("click", hello);


Removing Event Listeners

removeEventListener() removes attached events.

Syntax:
element.removeEventListener("event", functionName);

Example:
btn.removeEventListener("click", hello);


Mouse Events

click → Runs when clicked.

dblclick → Runs on double click.

mouseover → Mouse enters element.

mouseout → Mouse leaves element.

mousemove → Runs continuously while moving mouse.

mousedown → Mouse button pressed.

mouseup → Mouse button released.


Keyboard Events

keydown → Runs when key pressed.

keyup → Runs when key released.

keypress → Runs while typing.


Input & Form Events

input → Runs while typing.

change → Runs when value changes.

focus → Runs when input selected.

blur → Runs when input loses focus.

submit → Runs when form submitted.


Window Events

load → Runs when page fully loads.

resize → Runs when browser resized.

scroll → Runs during page scrolling.


The Event Object

JavaScript automatically provides an event object containing event information.

Syntax:
element.addEventListener("click", function(event){ });

Important Properties:
• event.target
• event.type
• event.key
• event.clientX
• event.clientY


preventDefault()

preventDefault() stops the browser’s default behavior.

Example:
Prevent form from refreshing page after submit.

Syntax:
event.preventDefault();


event.target vs event.currentTarget

event.target
Actual clicked element.

event.currentTarget
Element that owns the event listener.

Example:
Clicking button inside div:
target → button
currentTarget → div


Event Bubbling

Events move upward from child to parent.

Example:
Button inside div clicked:
Button Event → Div Event


Event Capturing

Opposite of bubbling.

Event travels from parent to child.

Syntax:
addEventListener("click", function(){ }, true);


stopPropagation()

stopPropagation() stops bubbling/capturing.

Syntax:
event.stopPropagation();


Event Delegation

Instead of attaching listeners to many child elements,
attach one listener to parent element.

Uses Event Bubbling internally.

Benefits:
• Better Performance
• Less Memory Usage
• Easier for Dynamic Elements


Arrow Functions with Events

Modern JavaScript commonly uses arrow functions.

Example:
btn.addEventListener("click", () => {
    console.log("Clicked");
});


Multiple Event Listeners

Multiple listeners can be attached to same element.

Example:
btn.addEventListener("click", firstFunction);
btn.addEventListener("click", secondFunction);


Confusion Topics

1. Bubbling vs Capturing
Bubbling → Child to Parent
Capturing → Parent to Child

2. target vs currentTarget
target → Actual clicked element
currentTarget → Listener owner

3. preventDefault()
Stops browser default action.
