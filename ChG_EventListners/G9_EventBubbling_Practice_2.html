How Event Bubbling Actually Works


When you click a button, only the <button> element is physically clicked.

But in JavaScript, the event does not stop there.

The event travels upward through parent elements inside the DOM tree.

Structure:

main
└── div.a
      └── div.b
           └── div.c
               └── button

If the button is clicked:

• button receives the event first
• then div.c
• then div.b
• then div.a
• then main
• then body
• then html
• then document

The event keeps climbing upward through parent/ancestor elements.

This behavior is called Event Bubbling.
