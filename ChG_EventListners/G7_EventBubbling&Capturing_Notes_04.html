Ch G / Part VI : "Event Bubbling & Capturing Notes 04" in JS

Event Bubbling

Definition: Event starts from the target element and moves upward to parent elements.

Flow:
Child → Parent → Grandparent

Example:
button.addEventListener("click", function(){
    console.log("Button Clicked");
});

div.addEventListener("click", function(){
    console.log("Div Clicked");
});

Clicking button → button event runs first, then div event.


Event Capturing

Definition: Event moves from parent element down to target element.

Flow:
Parent → Child

Syntax:
element.addEventListener("click", function(){ }, true);

Here, true enables capturing mode.


Easy Memory Trick

Bubbling → Inside to Outside ↑

Capturing → Outside to Inside ↓
