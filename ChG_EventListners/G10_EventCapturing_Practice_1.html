How to Enable Event Capturing?



By default, addEventListener() uses bubbling phase.

To enable capturing phase, you must pass:

true

as the third argument inside addEventListener().

Syntax:

element.addEventListener("click", function(){
    console.log("Capturing");
}, true);

Here:
• true → Capturing Phase
• false/default → Bubbling Phase


MOST IMPORTANT CONCEPT : Event Flow



Events ALWAYS travel in this order:

1. Capturing Phase
Parent → Child

2. Target Phase
Actual clicked element

3. Bubbling Phase
Child → Parent


FULL EVENT JOURNEY

Suppose button is clicked.

DOM Structure:

document
└── html
    └── body
        └── .a
            └── .b
                └── .c
                    └── button


PHASE 1 : Capturing Phase

The event starts from the top of DOM and travels downward.

Path:

document
↓
html
↓
body
↓
.a
↓
.b
↓
.c
↓
button

Only listeners with true react during capturing.

.a runs
Because it uses:
true

Output:
a is invoked !

.b does NOT run
Because .b is a bubbling listener.

.c runs
Because .c also uses:
true

Output:
c is invoked !


PHASE 2 : Target Phase

Now the event reaches the actual clicked element:

button

So the button listener runs.

Output:
btn is invoked !


PHASE 3 : Bubbling Phase

Now the event starts moving upward.

Path:

button
↑
.c
↑
.b
↑
.a

Only bubbling listeners react now.

.c does NOT run again
Because .c was capturing only.

.b runs now
Because .b is a bubbling listener.

Output:
b is invoked !

.a does NOT run again
Because .a was capturing listener only.


FINAL OUTPUT

a is invoked !
c is invoked !
btn is invoked !
b is invoked !
