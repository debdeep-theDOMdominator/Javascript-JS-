What is Scope in JavaScript?

Definition:
Scope defines where variables can be accessed in a program.

It controls the visibility and lifetime of variables.

JavaScript mainly has 3 types of scope:
• Global Scope
• Function Scope
• Block Scope


Global Scope

Variables declared outside all functions and blocks belong to the global scope.

These variables can be accessed from anywhere in the program.

Example:
let username = "Sam";

function showName(){
    console.log(username);
}

showName();


Function Scope

Variables declared inside a function are accessible only inside that function.

Outside the function, those variables do not exist.

Example:
function test(){
    let age = 20;
    console.log(age);
}

test();

// console.log(age); ❌ Error


Block Scope

Variables declared using let and const inside blocks {} are block scoped.

They only work inside that block.

Example:
if(true){
    let marks = 90;
    console.log(marks);
}

// console.log(marks); ❌ Error


var vs let vs const

var
• Function Scoped
• Can be redeclared
• Old way

let
• Block Scoped
• Can be updated
• Modern JavaScript

const
• Block Scoped
• Cannot be updated
• Used for fixed values


Lexical Scope

Lexical Scope means inner functions can access variables of outer functions.

Scope is determined by where functions are written in code.

Example:
function outer(){
    let message = "Hello";

    function inner(){
        console.log(message);
    }

    inner();
}

outer();


Dynamic Scope vs Lexical Scope

JavaScript uses Lexical Scope, NOT Dynamic Scope.

Lexical Scope depends on where functions are written.
Dynamic Scope would depend on where functions are called.

JavaScript always follows lexical scoping.


What is Execution Context?

Execution Context is the environment where JavaScript code runs.

It contains:
• Variables
• Functions
• this keyword
• Scope information

JavaScript creates an execution context whenever a script or function runs.


Types of Execution Context

1. Global Execution Context
Created when JS file starts running.

2. Function Execution Context
Created whenever a function is called.


Phases of Execution Context

Every execution context has 2 phases:

1. Memory Creation Phase
JavaScript allocates memory for variables and functions.

Variables initialized with:
• undefined

Functions stored completely in memory.

2. Execution Phase
Code executes line by line.
Variables receive actual values.


Example of Execution Context

Code:

var x = 10;

function test(){
    console.log("Hello");
}

test();

Memory Phase:
x → undefined
test → full function stored

Execution Phase:
x → 10
test() executes


Call Stack

JavaScript uses a Call Stack to manage execution contexts.

Functions are pushed into the stack when called and removed after execution.

Example:
main()
    ↓
test()
    ↓
display()

Last entered function executes first.

This follows the LIFO rule:
Last In First Out.


What is Closure?

Definition:
A Closure is created when a function remembers variables from its outer scope even after the outer function has finished execution.

Closures allow functions to preserve data.


Closure Example

function outer(){
    let count = 0;

    function inner(){
        count++;
        console.log(count);
    }

    return inner;
}

let counter = outer();

counter();
counter();
counter();


How Closures Work

Even after outer() finishes execution,
the inner() function still remembers the variable count.

This happens because JavaScript stores references to outer variables.


Closure vs Returning Function

Returning a function does NOT automatically mean closure.

Closure happens only when returned function remembers outer variables.

Example:
function outer(){
    let name = "Sam";

    return function(){
        console.log(name);
    };
}


Scope Chain

JavaScript searches variables in a chain.

First:
Current Scope

Then:
Parent Scope

Then:
Global Scope

This searching mechanism is called the Scope Chain.


Closure Use Cases

Closures are commonly used for:

• Private Variables
• Data Hiding
• Counters
• Function Factories
• Encapsulation
• Maintaining State


Private Counter Example

function counter(){
    let count = 0;

    return {
        increment : function(){
            count++;
            console.log(count);
        },

        decrement : function(){
            count--;
            console.log(count);
        }
    };
}

let c1 = counter();

c1.increment();
c1.increment();
c1.decrement();


Mindset Note

Closures are how JavaScript gives memory to your logic.

Functions can remember values even after execution finishes.


Easy Memory Trick

Scope → Where variables can be used.

Execution Context → Environment where code runs.

Closure → Function remembers outer variables.
