What is the this Keyword?

Definition:
this is a special keyword in JavaScript that refers to the object that is currently executing the function.

The value of this changes depending on how the function is called.

Important:
this does NOT depend on where function is written.
It depends on HOW the function is called.


DIFFERENT VALUES OF 'this' AT DIFFERENT LOCATIONS -

1. inside global : window
2. inside FUNCTION : window
3. inside method with `es5 FUNCTION` : object
4. inside method with `es6 ARROW FUNCTION` : window
5. `es5 FUNCTION` inside `es5 FUNCTION` : window
6.`ARROW FUNCTION` inside `es5 FUNCTION` : object
7. inside EVENT HANDLER : element
8. inside `CLASS` : blank object


this in Global Scope

In the browser global scope,
this refers to the window object.

Example:
console.log(this);

Output:
window object


this inside Normal Function

In a regular function,
this usually refers to the global object (window) in non-strict mode.

Example:
function test(){
    console.log(this);
}

test();

Output:
window object


this inside Object Method

When a function is called as an object method,
this refers to that object.

Example:
let student = {
    name : "Sam",

    showName : function(){
        console.log(this.name);
    }
};

student.showName();

Output:
Sam


this inside Event Listener

Inside an event listener,
this refers to the element that triggered the event.

Example:
let btn = document.querySelector("button");

btn.addEventListener("click", function(){
    console.log(this);
});

Output:
button element


this inside Classes

Inside classes,
this refers to the current object created from the class.

Example:
class User{
    constructor(name){
        this.name = name;
    }

    show(){
        console.log(this.name);
    }
}

let u1 = new User("Alex");
u1.show();


Arrow Functions and this

Arrow functions do NOT create their own this.

They inherit this from their surrounding scope.

This is called Lexical this.

Example:
let obj = {
    name : "John",

    show : () => {
        console.log(this.name);
    }
};

obj.show();

Output:
undefined


Why Arrow Functions Lose this in Methods

Arrow functions do not bind their own this.

They simply use the surrounding scope’s this.

So inside objects,
arrow functions should generally NOT be used as methods.


Correct Use of Arrow Function

Arrow functions are useful inside callbacks where we want to preserve outer this.

Example:
let person = {
    name : "Sam",

    show : function(){

        setTimeout(() => {
            console.log(this.name);
        },2000);
    }
};

person.show();


Manual Binding of this

JavaScript provides methods to manually control this.

Important methods:
• bind()
• call()
• apply()


call() Method

call() immediately invokes a function with a specific this value.

Syntax:
functionName.call(object);

Example:
function greet(){
    console.log(this.name);
}

let user = {name : "Alex"};

greet.call(user);


apply() Method

apply() works like call(),
but arguments are passed as an array.

Syntax:
functionName.apply(object,[arguments]);

Example:
function add(a,b){
    console.log(a+b);
}

add.apply(null,[10,20]);


bind() Method

bind() does NOT immediately execute the function.

It returns a new function with fixed this value.

Syntax:
functionName.bind(object);

Example:
function hello(){
    console.log(this.name);
}

let obj = {name : "Sam"};

let newFunction = hello.bind(obj);

newFunction();


this inside Event Listeners Confusion

Inside normal event listener functions,
this refers to the clicked element.

But inside arrow functions,
this comes from outer scope.

Example:
btn.addEventListener("click", () => {
    console.log(this);
});

Here,
this may refer to window object.


Call Site Principle

MOST IMPORTANT RULE:

The way a function is CALLED determines the value of this.

This is known as the Call Site Principle.


Custom Logger Object Example

let logger = {
    name : "System Logger",

    normalFunction : function(){
        console.log(this.name);
    },

    arrowFunction : () => {
        console.log(this.name);
    }
};

logger.normalFunction();
logger.arrowFunction();


Using bind() to Fix Context

Sometimes functions lose their correct this value.

bind() helps permanently fix the context.

Example:
let person = {
    name : "David"
};

function show(){
    console.log(this.name);
}

let fixedFunction = show.bind(person);

fixedFunction();


Easy Memory Trick

Normal Function:
this depends on caller.

Arrow Function:
Takes this from outer scope.

bind()
Permanently fixes this.
